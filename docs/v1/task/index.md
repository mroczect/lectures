# Tugas

Daftar tugas semester ini. Dikelompokkan berdasarkan **status** dan **mata kuliah**.

::: info Tentang Halaman Ini
Folder tugas dibagi dua:

- **[Aktif](/v1/task/undone/)** — tugas yang belum/sedang dikerjakan.
- **[Selesai](/v1/task/done/)** — arsip tugas yang sudah dikumpulkan.

Setiap mata kuliah punya halaman indeks tugasnya masing-masing di dalam folder `undone/` atau `done/`.
:::
