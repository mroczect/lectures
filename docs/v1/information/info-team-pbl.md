## Deskripsi Proyek

### Kelompok Iqbal Afif

::: details PBL-TRPL101 — Aplikasi Pengelolaan Warung
Platform web untuk membantu pemilik warung mencatat transaksi dan mengelola stok barang.

**Fitur utama:**

- Pencatatan transaksi harian
- Manajemen stok real-time
- Laporan untung-rugi
- Notifikasi stok menipis
  :::

::: details PBL-TRPL102 — Aplikasi Informasi Warga
Platform web untuk mempermudah komunikasi RT/RW dengan warga — informasi, iuran, dan administrasi.

**Fitur utama:**

- Papan pengumuman digital
- Pencatatan iuran warga
- Data kependudukan sederhana
- Pengajuan surat online
  :::

::: details PBL-TRPL103 — Aplikasi Pengelolaan Bank Sampah

**Fitur utama:**

- Konversi otomatis ke saldo
- Riwayat transaksi
- Info harga sampah
  :::

::: details PBL-TRPL104 — Aplikasi Lapak UMKM

**Fitur utama:**

- Jadwal pengantaran
- Riwayat dan ulasan
  :::

## Pola Fitur Umum

Meskipun konteksnya berbeda, ada pola fitur yang berulang di hampir semua proyek:

| Pola                       | Deskripsi                                         | Contoh Proyek      |
| -------------------------- | ------------------------------------------------- | ------------------ |
| CRUD + Status              | Tambah, baca, ubah, hapus dengan indikator status | 101, 106, 111, 113 |
| Pemesanan & Validasi Kuota | Pesan, cek ketersediaan, cegah duplikasi          | 105, 112, 113      |
| Unggah File/Bukti          | Lampirkan foto, dokumen, atau bukti transfer      | 107, 108, 109, 110 |
| Notifikasi & Pengingat     | Sistem memberi tahu saat kondisi tertentu         | 101, 106, 107, 114 |
| Dashboard & Rekap          | Halaman admin dengan ringkasan data               | 107, 110, 111, 115 |

## FAQ

::: details Apakah boleh memilih proyek sendiri?
**Tidak.** Pembagian proyek ditetapkan dosen Manpro. Kalau ada preferensi kuat, diskusikan dengan dosen pengampu di awal semester.
:::

::: details Berapa anggota tiap tim?
Umumnya **6 mahasiswa** per tim — lihat [Judul dan Tim PBL](/v1/information/judul-dan-team-pbl).
:::

::: details Boleh tukar proyek dengan tim lain?
Biasanya **tidak boleh** kecuali ada alasan kuat (konflik jadwal/masalah kolaborasi). Ajukan resmi ke dosen Manpro.
:::

::: details Apa hubungan proyek PBL dengan mata kuliah?
Setiap proyek melibatkan minimal 4 mata kuliah:

- **RPL101** — analisis & perancangan
- **RPL104** — dokumen SRS
- **RPL105** — implementasi web
- **RPL106** — skema database
  :::

::: details Bagaimana kalau tim tidak solid?

1. Diskusikan internal dulu.
2. Minta ketua tim memediasi.
3. Kalau masih berlanjut, hubungi dosen Manpro.
   :::
