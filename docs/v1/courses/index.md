## Sekilas

| Mata Kuliah | SKS | Terhubung PBL |     Semester     |
| :---------: | :-: | :-----------: | :--------------: |
|      7      | 21  |       5       | Ganjil 2026/2027 |

Semester pertama dirancang sebagai **satu perjalanan terpadu** — bukan tujuh mata kuliah terpisah. Fondasi teori dari matematika dan algoritma mengalir ke praktik di analisis kebutuhan, pemrograman web, dan basis data, semuanya bermuara pada satu **proyek PBL bersama**.

## Tiga Fase Belajar

| Fase             | Fokus                        | Mata Kuliah              |
| ---------------- | ---------------------------- | ------------------------ |
| **Fondasi**      | Logika, matematika, karakter | RPL102, RPL103, PK001RPL |
| **Jembatan**     | Proses RPL, kebutuhan        | RPL101, RPL104           |
| **Implementasi** | Web, basis data              | RPL105, RPL106           |

**Benang merah:** RPL104 menghasilkan dokumen SRS yang jadi dasar implementasi di RPL105 dan RPL106. RPL102 dan RPL103 menyokong seluruh rantai.

::: tip Strategi Belajar

- **Jangan belajar terpisah** — proyek PBL adalah benang merah.
- **Dahulukan RPL104 & RPL106** — luarannya prasyarat implementasi.
- **Gunakan RPL102 & RPL103** sebagai perangkat — akan dipakai sepanjang semester.
- **Jaga PK001RPL** — karakter sama pentingnya dengan skill teknis.

:::

## FAQ

::: details Apakah semua mata kuliah harus diambil?
Ya. Ketujuhnya adalah paket semester pertama yang sudah ditetapkan kurikulum.
:::

::: details Mata kuliah mana yang paling berat?
**RPL105** (4 SKS, cakupan luas) dan **RPL104** (luaran SRS komprehensif).
:::

::: details Perlu bisa coding sebelum masuk?
**Tidak.** RPL102 dirancang untuk pemula.
:::

::: details Bagaimana hubungan RPL101, RPL104, RPL105?
RPL101 = kerangka kerja → RPL104 = dokumen SRS → RPL105 = implementasi. Tanpa RPL104, RPL105 tanpa arah.
:::

::: details PK001RPL terhubung PBL?
**Tidak langsung.** Berjalan paralel sebagai pembangunan karakter — relevan untuk kerja tim PBL.
:::
