## Deskripsi

Pengenalan perangkat lunak dan rekayasa perangkat lunak: aktivitas pengembangan, manajemen, dokumentasi dan standar, model proses, dan peran perekayasa.

## Materi

| Pertemuan | Topik                                           |
| :-------: | ----------------------------------------------- |
|     1     | Pendahuluan & Etika — peran perekayasa, SWEBOK  |
|     2     | Analisis — kebutuhan fungsional & nonfungsional |
|    3–4    | Perancangan — arsitektur, komponen, antarmuka   |
|     5     | Implementasi — design pattern, reuse            |
|     6     | Pengujian — komponen, sistem, use case, TDD     |
|     7     | Deployment — instalasi & aktivasi               |
|     8     | Manajemen proyek — risiko, tim, perencanaan     |
|   9–10    | Model proses — Waterfall, Iteratif, Agile       |
|    11     | Agile — Scrum                                   |
|    12     | DevOps — CI/CD, otomatisasi                     |
|    13     | Evolusi PL — maintenance, reuse                 |
| Tambahan  | LLM/GenAI untuk software engineering            |

## Tujuan Pembelajaran

Setelah menyelesaikan mata kuliah, mahasiswa mampu:

1. Menjelaskan peran perekayasa perangkat lunak dalam masyarakat.
2. Memformulasikan dan menjustifikasi pemecahan masalah tim.
3. Mendesain aplikasi sederhana.
4. Menuliskan dokumentasi teknis.
5. Bekerja sama efektif dalam tim.
6. Mempresentasikan hasil kerja dalam Bahasa Inggris.
