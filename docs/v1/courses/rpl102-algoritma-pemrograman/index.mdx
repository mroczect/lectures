## Contoh Kode

### Percabangan

```python
nilai = 85
if nilai >= 85:
    grade = "A"
elif nilai >= 70:
    grade = "B"
else:
    grade = "C"
print(f"Nilai {nilai} → Grade {grade}")
```

### Pengulangan

```python
# for loop — jumlah iterasi diketahui
for i in range(1, 6):
    print(f"Iterasi ke-{i}")

# while loop — faktorial, iterasi bergantung kondisi
n = 5
faktorial = 1
while n > 1:
    faktorial *= n
    n -= 1
print(f"5! = {faktorial}")
```

`range(1, 6)` menghasilkan 1, 2, 3, 4, 5 — batas atas tidak inklusif.

### List & Dictionary

```python
# List — mutable, akses via index
nilai = [85, 90, 78, 92, 88]
nilai.append(95)
print(nilai[1:4])       # slicing
print(max(nilai), sum(nilai))

# Dictionary — key-value
mahasiswa = {"nama": "Budi", "nim": "4342611034"}
mahasiswa["angkatan"] = "2026"

for key, value in mahasiswa.items():
    print(f"{key}: {value}")
```

### Fungsi & Prosedur

```python
def luas_persegi(sisi):
    return sisi * sisi

def sapa(nama, sapaan="Halo"):
    return f"{sapaan}, {nama}!"

def cetak_header(judul):
    print("=" * 40)
    print(judul.center(40))
    print("=" * 40)

print(luas_persegi(5))    # 25
print(sapa("Budi"))       # Halo, Budi!
cetak_header("LAPORAN NILAI")
```

Fungsi mengembalikan nilai (`return`). Prosedur melakukan efek tanpa nilai balik.

### Input & File

```python
# input selalu return string — konversi eksplisit
nama = input("Nama: ")
umur = int(input("Umur: "))

# tulis file
with open("catatan.txt", "w") as f:
    f.write(f"{nama}, {umur}\n")

# baca file
with open("catatan.txt", "r") as f:
    print(f.read())
```

`with open(...)` menutup file otomatis, termasuk saat terjadi error.

## Kesalahan Umum Pemula

| Error         | Penyebab                         | Solusi                         |
| ------------- | -------------------------------- | ------------------------------ |
| `SyntaxError` | Lupa `:` atau indentasi salah    | Cek struktur blok              |
| `TypeError`   | Operasi antar tipe beda          | Konversi: `int(input())`       |
| `NameError`   | Pakai variabel yang belum dibuat | Cek ejaan & urutan definisi    |
| `IndexError`  | Akses index di luar rentang      | Cek `len(list)`                |
| `KeyError`    | Akses key dict yang tidak ada    | Pakai `dict.get(key, default)` |

Kesalahan paling umum: `=` (assignment) vs `==` (comparison).
