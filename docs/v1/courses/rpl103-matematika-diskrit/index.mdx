## Deskripsi

Konsep dasar matematika diskrit sebagai fondasi RPL: himpunan, matriks, relasi, fungsi, logika matematika, kombinatorik, aljabar Boolean, teori bilangan, dan teori graf. Menekankan pemodelan masalah dan penerapan pada struktur data, basis data, kriptografi sederhana, serta optimasi jaringan.

Mata kuliah **sepenuhnya daring** — tidak ada sesi praktikum luring. Kamera wajib aktif saat kuliah.
