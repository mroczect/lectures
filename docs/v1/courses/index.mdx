## Keterkaitan PBL

Empat mata kuliah terhubung langsung ke proyek PBL:

-   **RPL101** — tahapan pengembangan, dokumentasi, presentasi.
-   **RPL104** — SRS dari kebutuhan stakeholder.
-   **RPL105** — kode aplikasi web.
-   **RPL106** — skema database.

Dua mata kuliah mendukung: **RPL102** (algoritma) dan **RPL103** (logika matematika). **PK001RPL** berjalan paralel, tidak terhubung langsung.
