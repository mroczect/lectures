# Pengantar

Dokumentasi kuliah Program Studi Teknologi Rekayasa Perangkat Lunak, Politeknik Negeri Batam.

Isinya: materi kuliah, jadwal, tugas, dan referensi per semester.

## Struktur

Dokumentasi dipisah jadi dua jenis:

-   **Global** — berlaku untuk semua semester. Ada di root `docs/`: halaman ini, [format](/docs/format/page), [lisensi](/docs/license).
-   **Berversi** — per semester. Ada di folder versi: [`/docs/v1/`](/docs/v1/), nantinya `/docs/v2/`.

Versi lama dibekukan saat semester baru dimulai. Tujuannya supaya materi semester lalu tetap bisa diakses dan dikutip tanpa berubah.

## FAQ

**Ini dokumentasi resmi kampus?**
Bukan. Ini catatan pribadi, sumbernya dari RPS dan e-learning resmi.

**Komersial boleh?**
Tidak, tanpa izin.

**Kenapa pakai versi?**
Supaya materi semester lama tetap stabil dan bisa dikutip.

**Data saya tidak cocok dengan jadwal asli?**
Konfirmasi ke koordinator kelas atau cek e-learning. Halaman ini hanya rangkuman.
