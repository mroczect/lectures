## Struktur Dokumentasi

| Jenis        | Lokasi       | Cakupan       | Contoh                     |
| ------------ | ------------ | ------------- | -------------------------- |
| **Global**   | Root `docs/` | Semua versi   | `/`, `/format`, `/license` |
| **Berversi** | Folder versi | Satu semester | `/v1/*`, `/v2/*`           |

### Versi Dokumentasi

| Versi  |    Status    |     Periode      | Deskripsi                             | Tautan                |
| :----: | :----------: | :--------------: | ------------------------------------- | --------------------- |
| **v1** |    Aktif     | Ganjil 2026/2027 | Rilis awal — materi semester pertama. | [**Buka v1 →**](/v1/) |
|   v2   | Direncanakan | Genap 2026/2027  | Menyusul semester berikutnya.         | _Belum tersedia_      |

::: info Kenapa pakai versi?

1. **Preservasi** — materi semester lalu tetap bisa diakses dan dikutip.
2. **Kejelasan** — selalu tahu halaman ini milik semester mana.
3. **Evolusi** — struktur bisa berkembang tanpa merusak tautan lama.

Versi lama **dibekukan** saat semester baru dimulai — hanya koreksi kritis yang dilakukan.
:::

## FAQ

::: details Apa itu proyek ini?
**Lectures** adalah dokumentasi pribadi yang merangkum materi, jadwal, tugas, dan referensi akademik untuk Prodi Teknologi Rekayasa Perangkat Lunak, Politeknik Negeri Batam. Ini **bukan publikasi resmi** kampus, tetapi bersumber dari dokumen resmi seperti RPS dan e-learning.
:::

::: details Siapa yang boleh menggunakannya?
**Semua orang** dengan ketentuan CC BY-NC-SA 4.0 — mahasiswa, dosen, dan masyarakat umum. Penggunaan komersial **tidak diizinkan** tanpa izin.
:::

::: details Kenapa pakai versi?
Versi menyimpan semester lalu sebagai rekam jejak. Saat semester baru dimulai, versi baru dibuat — versi lama dibekukan, sehingga kutipan tetap valid dan materi lama tetap bisa diakses.
:::

::: details Di mana daftar mata kuliah saya?
Buka [**Mata Kuliah**](/v1/courses/) — berisi 7 mata kuliah semester 1.
:::

::: details Di mana jadwal kuliah saya?
Halaman [**Jadwal Kuliah**](/v1/information/jadwal-kuliah) menampilkan jadwal kelas malam. Jika berbeda, konfirmasi ke koordinator kelas atau e-learning resmi.
:::

::: details Di mana tim PBL saya?
Buka [**Judul dan Tim PBL**](/v1/information/judul-dan-team-pbl) — berisi 30 tim per kelas (Pagi A/B/C dan Malam A/B/C).
:::

::: details Bagaimana kalau ada kesalahan?
Buka **issue** di [GitHub](https://github.com/mroczect/lectures/issues), atau kirim **pull request**. Untuk typo/format boleh edit langsung; untuk koreksi konten, buat issue dulu.
:::

::: details Bagaimana dokumentasi diperbarui?
Diperbarui aktif selama semester — mingguan untuk materi & tugas, insidental untuk koreksi, dan antar semester untuk perubahan struktur.
:::
