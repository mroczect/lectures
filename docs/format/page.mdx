# Format & Aturan

Acuan penulisan untuk siapa pun yang menambah atau mengedit konten di dokumentasi ini.

Empat prinsip: konsisten, deskriptif, scalable, ramah kontributor. Semua aturan di bawah turun dari situ.

## Penamaan file

Gunakan **kebab-case**, **lowercase**, **deskriptif**.

| Benar               | Salah              |
| ------------------- | ------------------ |
| `kontak-dosen.mdx`  | `kontakDosen.mdx`  |
| `jadwal-kuliah.mdx` | `JadwalKuliah.mdx` |
| `info-team-pbl.mdx` | `itp.mdx`          |

Hindari:

-   Spasi (`kontak dosen.mdx`) — jadi `%20` di URL
-   Kapital campur (`JadwalKuliah.mdx`) — case-sensitive di Linux
-   Underscore (`kontak_dosen.mdx`) — bukan konvensi web
-   Singkatan (`jk.mdx`) — tidak deskriptif
-   Karakter unik (`kontak-dosen!.mdx`) — bisa bermasalah di URL dan Git

## Materi bertimestamp

Untuk file materi (kecuali `index.mdx`), pakai pola:
```

{YYYY-MM-DD}_{course_id}_{course*name}*{description}.mdx

````

| Komponen | Format | Contoh |
| --- | --- | --- |
| timestamp | `YYYY-MM-DD` | `2026-09-15` |
| course_id | kode lowercase | `rpl101`, `rpl106`, `pk001` |
| course_name | sama dengan nama folder | `pengantar-rpl` |
| description | kebab-case singkat | `er-diagram` |

Contoh:

| Salah | Benar |
| --- | --- |
| `materi-01-pengenalan.md` | `2026-09-01_rpl101_pengantar-rpl_pengenalan.mdx` |
| `materi-02-analisis.md` | `2026-09-08_rpl101_pengantar-rpl_analisis.mdx` |
| `15-09-2026-rpl104-intro.md` | `2026-09-15_rpl104_analisis-kebutuhan-pl_intro.mdx` |

Timestamp di depan bikin file otomatis urut kronologis saat di-sort — sesuai urutan pertemuan.

**Pengecualian:** `index.mdx` di setiap folder tidak pakai timestamp. Dia landing page folder.

## Ekstensi

Semua file dokumentasi pakai `.mdx`. Markdown murni tetap valid, tapi `.mdx` memungkinkan pakai komponen React saat perlu.

`.md` tidak dipakai, kecuali di luar `docs/` (mis. `README.md` di root repo).

Cek file `.md` yang tersisa:

```bash
find docs -name '*.md' -not -name '*.mdx'
````

Rename massal kalau ada:

```bash
find docs -name '*.md' -not -name '*.mdx' -exec sh -c 'mv "$1" "${1%.md}.mdx"' _ {} \;
```

## Frontmatter

Setiap file wajib punya minimal:

```yaml
---
title: Judul Halaman
description: Deskripsi singkat.
---
```

Field lengkap:

| Field              |   Wajib    | Fungsi                                         |
| ------------------ | :--------: | ---------------------------------------------- |
| `title`            |     ✅     | Judul halaman, tampil di tab & TOC             |
| `description`      | disarankan | Untuk SEO dan social preview                   |
| `slug`             | disarankan | URL kustom, terutama untuk file bertimestamp   |
| `sidebar_position` | disarankan | Urutan di sidebar, makin kecil makin atas      |
| `sidebar_label`    |  opsional  | Label alternatif kalau `title` terlalu panjang |

**Landing page course:**

```yaml
---
title: RPL106 — Pengantar Basis Data
description: Materi, praktikum, dan referensi mata kuliah RPL106.
slug: /v1/courses/rpl106-pengantar-basis-data/
sidebar_position: 70
---
```

**Materi bertimestamp** — slug tidak menyertakan timestamp biar URL bersih:

```yaml
---
title: 'Pertemuan 2 — ER Diagram'
description: Pemodelan data konseptual.
slug: /v1/courses/rpl106-pengantar-basis-data/er-diagram
sidebar_position: 2
---
```

## Urutan sidebar

Ditentukan oleh `sidebar_position` di frontmatter.

|      Nilai      | Dipakai untuk                       |
| :-------------: | ----------------------------------- |
|        1        | `index.mdx` (landing page)          |
|       2+        | Materi di dalam folder course       |
| 10, 20, 30, ... | Course dalam kategori, kelipatan 10 |

Course pakai kelipatan 10 supaya mudah menyisipkan course baru tanpa renumber:

```
10  pk001-pendidikan-agama
20  rpl101-pengantar-rpl
30  rpl102-algoritma-pemrograman
40  rpl103-matematika-diskrit
50  rpl104-analisis-kebutuhan-pl
60  rpl105-pemrograman-web
70  rpl106-pengantar-basis-data
```

Materi dalam course pakai urutan biasa:

```
1  2026-09-01_..._pengenalan.mdx
2  2026-09-08_..._er-diagram.mdx
3  2026-09-15_..._normalisasi.mdx
```

## Format konten

Struktur halaman standar: H1 → metadata → konten → halaman terkait. Metadata (kode, SKS, dosen), tagline, dan tip e-learning opsional.

### Tabel

Pakai alignment marker:

```markdown
| Kiri | Tengah | Kanan |
| :--- | :----: | ----: |
| teks |  teks  |   100 |
```

`:---` kiri, `:---:` tengah, `---:` kanan.

### Kode

Selalu pakai language tag:

````markdown
```python
def hello():
    print("hi")
```
````

Language yang sering dipakai: `bash`, `python`, `typescript`, `jsx`, `yaml`, `json`, `mdx`, `text`.

### Admonition

Empat tipe:

```mdx
:::note
:::

:::tip
:::

:::info
:::

:::warning
:::

:::danger
:::
```

Tanpa spasi setelah `:::`. `::: tip` salah, `:::tip` benar.

## MDX gotchas

MDX lebih ketat dari Markdown biasa. Ini yang sering bikin error.

**HTML comment:**

```mdx
<!-- error -->

{/* benar */}
```

**Curly braces:**

```mdx
Teks dengan {variabel} error.
Teks dengan `{variabel}` aman.
```

**Self-closing tag:**

```mdx
<br>     ❌
<br />   ✅

<img src="..." /> ✅
```

**`<details>` butuh blank line:**

```mdx
<details>
<summary>Judul</summary>

Konten di sini.

</details>
```

**Karakter `<` di teks:**

```mdx
Loading < 2 detik. ❌
Loading `< 2 detik`. ✅
Loading &lt; 2 detik. ✅
```

### Konversi dari VitePress

| VitePress           | Docusaurus             |
| ------------------- | ---------------------- |
| `::: tip`           | `:::tip`               |
| `::: info`          | `:::info`              |
| `::: details Judul` | `<details><summary>`   |
| `::: code-group`    | `<Tabs>` + `<TabItem>` |
| `<!-- -->`          | `{/* */}`              |
| `outline: deep`     | hapus                  |

## Checklist kontribusi

Sebelum commit atau PR:

-   [ ] Frontmatter lengkap (`title` minimal, `description` disarankan)
-   [ ] Ekstensi `.mdx`
-   [ ] Nama file kebab-case lowercase
-   [ ] Materi mengikuti format timestamp
-   [ ] `slug` di-set untuk materi bertimestamp
-   [ ] `sidebar_position` di-set
-   [ ] Tidak ada `<!-- -->` (pakai `{/* */}`)
-   [ ] Tidak ada `{` atau `}` literal
-   [ ] Semua tag self-closing
-   [ ] `<details>` punya blank line
-   [ ] Link internal valid
-   [ ] Kode pakai language tag
-   [ ] Admonition tanpa spasi setelah `:::`
-   [ ] Tidak ada typo

Verifikasi:

```bash
# Cek file .md tersisa
find docs -name '*.md' -not -name '*.mdx'

# Build — broken link akan muncul sebagai warning
bun run build
```

Kalau build gagal:

| Error                      | Solusi                            |
| -------------------------- | --------------------------------- |
| `Unexpected character '!'` | Ganti `<!-- -->` dengan `{/* */}` |
| `Unexpected character '{'` | Bungkus dengan backtick           |
| `Broken link`              | Cek URL atau target file          |
| `Duplicate routes`         | Hapus duplikat atau ubah `slug`   |
