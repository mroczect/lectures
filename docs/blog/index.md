### Format Nama File

Setiap tulisan disimpan di direktori `docs/blog/` dengan format penamaan file yang ketat agar terurut berdasarkan tanggal:

```text
docs/blog/YYYY-MM-DD-slug.md
```

**Contoh penamaan yang benar:**

```text
docs/blog/2026-09-15-setup-vitepress.md
docs/blog/2026-09-20-belajar-sql-join.md
```

### Template Standar Tulisan

Setiap membuat file tulisan baru, salin tempel _template_ frontmatter dan struktur dasar di bawah ini:

```markdown
---
title: Judul Tulisan
description: Deskripsi singkat untuk SEO.
date: 2026-09-15
tags: [tag1, tag2]
outline: deep
---

# Judul Tulisan

Pembuka — kenapa tulisan ini dibuat dan apa masalahnya.

## Section 1

Isi penjelasan, code block, atau gambar.

## Section 2

Isi lanjutan.

## Penutup

Kesimpulan dan harapan ke depan.
```
