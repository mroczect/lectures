#############
 Mata Kuliah
#############

.. meta::
   :description: Daftar mata kuliah Program Studi D4 Teknologi Rekayasa Perangkat Lunak - Politeknik Negeri Batam.
   :keywords: mata kuliah, TRPL, Polibatam, RPL, kurikulum

Berikut adalah daftar mata kuliah yang tersedia dalam dokumentasi ini.
Setiap mata kuliah memiliki halamannya sendiri yang memuat **materi**,
**tugas**, **catatan**, dan **referensi** terkait.

.. note::

   Dokumentasi ini disusun secara modular. Untuk menambah mata kuliah
   baru, cukup buat folder di bawah ``courses/`` dengan file
   ``index.rst`` di dalamnya. Sidebar akan otomatis menyesuaikan.
