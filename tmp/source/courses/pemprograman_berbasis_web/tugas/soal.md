E. Tugas Praktikum (Individu)
Buatlah sebuah halaman HTML sederhana (berkas index.html) yang berisi biodata diri lengkap. Halaman
wajib memuat komponen berikut:

1. Judul halaman pada tag <title> berisi nama Anda.
2. Sebuah heading utama (<h1>) berisi nama lengkap.
3. Paragraf (<p>) berisi deskripsi singkat tentang diri (program studi, semester, asal daerah, dsb).
4. Sebuah daftar (<ul> atau <ol>) berisi minimal 3 hobi atau keahlian.
5. Sebuah tautan (<a>) menuju media sosial, blog, atau portofolio pribadi.
6. Sebuah gambar (<img>) berupa foto atau avatar (opsional jika berkas gambar tidak tersedia).
   Ketentuan Pengumpulan
   • Berkas dikumpulkan dengan format nama: NIM_NamaLengkap.html
   • Dikumpulkan melalui sistem e-learning kampus sebelum pertemuan berikutnya.
   • Tugas dikerjakan secara mandiri; kemiripan struktur/isi yang identik antar mahasiswa akan diperiksa
