======
Tugas
======

.. meta::
   :description: Kumpulan tugas mata kuliah Program Studi Teknologi Rekayasa Perangkat Lunak Polibatam.
   :keywords: tugas, assignment, TRPL, Polibatam, kuliah

Bagian ini berisi kumpulan tugas dari setiap mata kuliah. Tugas disusun
berdasarkan mata kuliah dan pertemuan agar mudah dilacak dan dikerjakan
tepat waktu.

.. note::

   Pastikan setiap tugas dikumpulkan sesuai batas waktu yang ditentukan
   melalui e-learning IF Polibatam di https://learningif.polibatam.ac.id.
